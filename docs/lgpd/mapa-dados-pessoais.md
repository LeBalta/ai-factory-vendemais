# Mapa de Dados Pessoais - VendeMais

## Escopo atual

A versão acadêmica do VendeMais utiliza dados sintéticos controlados.

O fluxo de demonstração utiliza:

- nome;
- e-mail;
- empresa;
- cargo;
- origem do lead.

Os valores utilizados nos testes não representam pessoas reais.

## Classificação dos campos

### Nome

Em cenário real, constitui dado pessoal por permitir a identificação
direta da pessoa.

Uso pretendido:
identificação do contato comercial.

Base legal potencial em produção:
legítimo interesse, mediante avaliação específica do contexto e
documentação do balanceamento de interesses.

### E-mail

Quando associado a uma pessoa natural, constitui dado pessoal.

Uso pretendido:
identificação e contato empresarial.

Base legal potencial:
legítimo interesse ou execução de relação contratual/pré-contratual,
conforme a origem e finalidade da coleta.

### Empresa

Informação de pessoa jurídica não é, isoladamente, dado pessoal.

Quando combinada com nome, e-mail ou cargo, entretanto, pode integrar
o contexto identificável de uma pessoa natural.

### Cargo

Pode constituir informação associada a uma pessoa identificável.

Uso:
qualificação comercial do lead.

### Origem

Registra a procedência técnica/comercial do registro.

Quando vinculada a pessoa identificável, integra o conjunto de dados
pessoais tratados.

## Dados sensíveis

A solução não necessita nem deve coletar dados pessoais sensíveis
para sua finalidade de qualificação B2B.

## Dados utilizados na Etapa 2

A Etapa 2 permanecerá utilizando dados sintéticos para desenvolvimento,
testes e demonstração.

Nenhum dado pessoal real deverá ser utilizado nas evidências acadêmicas.

## Minimização

Somente os campos necessários à finalidade de qualificação comercial
devem ser processados.

Dados sem finalidade definida não devem ser coletados.
