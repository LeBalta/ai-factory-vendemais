\# AI Factory - VendeMais



\## Projeto



VendeMais é um projeto de automação de enriquecimento e qualificação de leads B2B.



O cenário herdado foi concebido para enriquecer leads de CRM, mas depende de execução manual e não possui uma operação automatizada e confiável.



\## Objetivo da Etapa 1



Evoluir o protótipo para uma solução:



\- automatizada;

\- versionada;

\- segura;

\- publicável;

\- testável;

\- com rollback;

\- com documentação técnica.



\## Stack inicial



\- n8n

\- GitHub

\- GitHub Actions

\- PowerShell

\- APIs externas de enriquecimento
